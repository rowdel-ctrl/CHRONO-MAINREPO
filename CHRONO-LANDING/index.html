Dashboard

Para sa guro, punong-guro at admin

Hiwalay na website ang dashboard. Nagsusulat ng tanong at sumusubaybay ng resulta ang guro, nakikita ng punong-guro ang buong paaralan, at ang ICT Coordinator ang nag-aalaga ng mga account.

Hakbang 1 · Magsulat

Isulat ang mga tanong.

Pumili ng era, tapos level, tapos ang mga tanong nito. Magdagdag ng sarili mong tanong, patayin ang iba, o piliin ang eksaktong tanong na makukuha ng mga estudyante. Walang makikita ang mga estudyante hanggang pindutin mo ang Send to students.

  • Nakagrupo ang mga era ayon sa grade at term
  • Hihintayin ng tanong na idinagdag mo ang pag-apruba ng punong-guro
  • Isang pindutan lang ang magpapadala ng lahat ng pagbabago

Kunin ang laro

I-download at i-install

APK file ang ChronoQuest na galing sa project team, hindi sa Play Store.

  1. I-download ang APKPindutin ang button. Mga 36 MB ang file.
  2. Buksan ang fileNasa notifications o sa Downloads folder mo ito.
  3. Payagan ang installMaaaring itanong ng Android kung pwedeng mag-install galing sa browser na ito. Pindutin ang Settings, tapos i-on ang Allow.
  4. Buksan ang ChronoQuest at mag-sign inGamitin ang class code ng guro. Wala pa? Pindutin ang Play as a guest para masubukan ang unang era.

Mga tanong

Magandang malaman

Nasa Play Store ba ang ChronoQuest?
Wala pa. Ini-install ito mula sa APK file na ibinibigay ng project team sa page na ito. Sa Android phone lang ito gumagana.
Bakit may babala ang Android tungkol sa hindi kilalang app?
Lumalabas ang babalang iyon sa kahit anong app na hindi galing sa Play Store. Galing sa ChronoQuest team ang file sa page na ito. Kapag nagtanong ang Android, payagan ang install mula sa browser mo, tapos pwede mo itong i-off ulit.
Kailangan ba ng internet para maglaro?
Kailangan ang internet para mag-sign in at maipadala ang puntos mo sa guro.
Saan ako kukuha ng class code?
Sa guro mo. Gagawa siya ng seksyon sa dashboard at ipapakita ang QR code o maikling class code. Gusto mo lang subukan? Pindutin ang Play as a guest sa unang screen. Unang era lang ang malalaro ng guest, walang ipapadala sa guro, at nagsisimula ito sa simula tuwing bubuksan.
Gagana ba ito sa phone ko?
Kailangan ng Android 7.0 pataas. Gumagana sa phone at tablet, 64-bit o 32-bit.
Sino ang sumusulat ng mga tanong?
Ang guro mo, mula sa dashboard. Galing sa question bank niya ang bawat tanong na sinasagot mo sa laro.
