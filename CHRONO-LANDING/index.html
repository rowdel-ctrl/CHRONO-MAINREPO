Run through Philippine history.

ChronoQuest is an Android runner game. Students jump, dodge and collect artifacts across six eras, then answer the questions their teacher wrote. Teachers see every result on the dashboard.

How it works

From class code to class results

Your teacher shows a QR code or a class code. Scan it or type it, then sign in.

Run through each era, collect artifacts, and answer a question for every one you pick up.

3

Teachers see results

Scores and answers appear on the dashboard, with item analysis for every question.

Dashboard

For teachers and admins

The dashboard is a separate website where you write questions, manage classes and read results.

Step 1 · Write

Write the questions. Set the time.

Pick an era, then a level, then its questions. Give every level one time limit, or change only a few. When you are ready, one button sends your changes to students.

  • Questions grouped by grade and term
  • One timer for the whole game, and a different time for any level
  • Students see nothing until you press Send to students

Get the game

Install on your phone

ChronoQuest comes as an APK file from the project team, not from the Play Store.

  1. Download the APKTap the button. The file is about 36 MB.
  2. Open the fileFind it in your notifications or your Downloads folder.
  3. Allow the installAndroid may ask to allow installs from this browser. Tap Settings, then switch Allow on.
  4. Open ChronoQuest and sign inUse the class code from your teacher. No code yet? Tap Play as a guest to try the first era.

Questions

Good to know

Is ChronoQuest on the Play Store?
Not yet. You install it from an APK file that the project team gives you on this page. It works on Android phones only.
Why does Android warn about an unknown app?
Android shows that warning for any app that does not come from the Play Store. The file on this page comes from the ChronoQuest team. When Android asks, allow the install from your browser, then you can switch it off again.
Do I need internet to play?
You need internet to sign in and to send your scores to your teacher.
Where do I get a class code?
From your teacher. They create a section on the dashboard and show you a QR code or a short class code. Just want to try the game? Tap Play as a guest on the first screen. A guest plays only the first era, nothing is sent to a teacher, and it starts fresh every time.
Will it work on my phone?
It needs Android 7.0 or newer. Phones and tablets, 64-bit or 32-bit, both work.
Who writes the questions?
Your teacher, from the dashboard. Each question you answer in the game comes from their question bank.

What ChronoQuest keeps about a student
  • Name and username
  • Class code, school and grade level
  • Scores, progress and answers to quiz questions
  • Password, stored scrambled so nobody can read it
  • Not stored: email address, phone number or location
